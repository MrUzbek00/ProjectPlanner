## Acceptance criterion — repeat

| Field | Definition |
| --- | --- |
| AC ID | AC-### |
| Requirement / rule IDs | Approved BIZ / FR / NFR / TR / BR references |
| Role / data scope | Confirmed actor and relevant ownership |
| Given | Defined initial state and data |
| When | Specific action/event |
| Then | Measurable output and resulting state |
| And | Required data, notification, audit or other side effects |
| Boundary / expected values | Exact test values supported by confirmed rules |
| Acceptance test IDs | AT references |

## Test case — repeat

| Field | Test definition |
| --- | --- |
| Test ID | AT-### |
| Title / test type | Specific behavior and category |
| Requirement / AC IDs | Actual references |
| Related page / process / API / card | Actual references or reasoned N/A; card pending before approval |
| Actor / permission / record scope | Confirmed setup |
| Preconditions | Initial state and prerequisite completion |
| Test data | Values, files and entity relationships; include expected calculation results |
| Environment / dependencies | Systems, versions, mocks if accepted, and limitations |
| Steps | Ordered actions below |
| Expected result | Observable response, state/data effects and required logs/notifications |
| Negative / boundary variation | Defined alternative case or separate AT IDs |
| Cleanup / isolation | Required restoration of test state where applicable |
| Execution status | NOT RUN |
| Execution evidence | Empty until actually executed; path/build/date/tester |
