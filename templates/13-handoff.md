The handoff has three layers. The **source of truth** is the Markdown records. The **human deliverables** are generated from them for stakeholders. The **machine handoff** is generated from them for downstream engineering systems. A recipient never needs the JSON to understand the project, and a downstream system never needs to reinterpret the Word files to execute it.

## Use the cards

Select the first READY task from the dependency-ordered roadmap (`executable_now` in `machine-handoff/backlog.json`). Supply its approved specification references, inputs and acceptance tests to the implementation team or coding agent. Implement only within separately authorized execution scope. A changed business rule returns through change control; it is not silently decided during coding.
